QUICK GUIDE

Paint with click/drag. Right-click erases. Add maps from the left. Use the Door tile to link rooms. Select an Event tile to write dialogue and optional story-variable conditions.

There is no fixed map dimension cap in the editor. Very large maps depend on your browser and computer memory.

PIXEL TILE WORKSHOP

Draw a 16 × 16 tile. Choose a color, then paint pixels. Transparent pixels let the room floor show through.
