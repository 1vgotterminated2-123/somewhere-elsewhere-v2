SOMEWHERE, ELSEWHERE / MAP EDITOR

TILE PALETTE

Selected: Floor. Click or drag on the map to paint.

Left-click / drag to paint. Right-click to erase to Floor. Choose Player Start, then click a tile to set the spawn position. Export creates a JSON map that can be imported from the game's main menu.

TILE INSPECTOR

HOW TO USE

Build rooms with floor, walls, water, paths, rugs, and interactive objects. Object tiles block movement and have built-in test dialogue. The Player Start marker determines where a new game begins.

Maps use a simple JSON format. Importing a map here replaces the editor canvas; importing the exported JSON in the game makes it the active game map and stores it in that browser.
